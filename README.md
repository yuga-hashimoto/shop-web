# mercari-ebay

メルカリで検索できる型番・商品と、eBayの**許諾された相場データ**を照合し、輸出販売における推定利益・ROI・販売リスクを提示するサービス。

> **ステータス：設計＋安全な自動化の土台（MOCK）。現在、実際のメルカリ/eBayから商品を収集したり、利益商品を一般公開したりはしていません。**

## 収益モデル

1. **広告**：一般公開する型番別相場・検索ガイド・比較記事。
2. **Pro（月額課金）**：高ROI商品、優先通知、詳細条件・ランキング。サーバー側の認可が必要。
3. **メルカリアンバサダー**：将来の検討枠。現行の転売促進用途ではガイドライン上禁止されるため **OFF固定**。通常の（非アフィリエイト）検索リンクを使う。

## 現状のGitHub Actions

| Workflow | 実行タイミング | 現在の内容 |
|---|---|---|
| [CI](.github/workflows/ci.yml) | push / PR / 手動 | 構文チェック、ユニットテスト、架空データでE2E相当のスモークテスト |
| [Scheduled discovery](.github/workflows/auto-discovery.yml) | 6時間ごと＋手動 | 架空の利益候補を計算、**DEMO_ONLY**で検証、7日保存のArtifactを出力 |

GitHub Actionsは継続稼働サーバーではありません。定期起動とテスト・集計のオーケストレーターとして使い、継続保存・認証・決済・公開APIは別の永続基盤を予定しています。

## ローカルで試す（Node.js 22+）

```sh
npm install
npm run ci
cat out/opportunities.json
```

上記の価格（例：40,000円）は架空のテストデータです。画面や記事で実売相場として表示してはいけません。

## 実データを扱う前に

- [ ] eBayアクティブ出品・実売データについて、それぞれ**取得・AI入力・保存・集計・第三者提供**を許可する契約を確認。
- [ ] メルカリ個別出品の自動取得・継続保存・画像再掲載について用途別許諾を確認。
- [ ] 価格データの鮮度と販売条件（送料、手数料、為替、商品状態）が一致することをテスト。
- [ ] Proの認可、広告・サブスクの法務・プライバシー要件を満たす。
- [ ] 取得・公開の誤りを止めるFeature Flag、データ削除手順と監視を用意。

**AIブラウザ操作で技術的に取得可能でも、利用権限を得たことにはなりません。** 制限回避・CAPTCHA突破・契約違反の自動収集は実装しません。
